# NC Quick Pass Expense Tracker

## Description
Managing and tracking toll road expenses, account reloads, and transit costs can often become cumbersome for daily commuters and frequent travelers using the North Carolina toll network. The **NC Quick Pass Expense Tracker** is a specialized, lightweight, and user-friendly web application designed specifically to help drivers monitor, categorize, and report their NC Quick Pass transactions with absolute precision. Built using modern JavaScript frameworks, this tool allows users to seamlessly log toll charges, review trip histories, generate digital receipts, and export expense reports for personal budgeting or business reimbursement. Whether you are navigating the Triangle Expressway, the I-77 Express Lanes, or managing multiple transponder accounts, this application simplifies your financial tracking so you can focus on the road ahead. Empower your commute with clean data visualization, responsive design, and intuitive receipt management tailored for every North Carolina driver.

## Features
* **Toll Transaction Logging:** Easily record date, amount, location, and transponder ID for every NC Quick Pass trip.
* **Dynamic Expense List:** View, filter, and delete recorded toll expenses in real-time.
* **Receipt Generation:** Automatically format selected trip entries into printable or downloadable digital receipts.
* **Responsive Dashboard:** Clean UI optimized for both desktop and mobile devices.
* **Local State Management:** Fast client-side rendering with persistent local storage support.

## Technologies Used
* **React.js:** Front-end component architecture and state management.
* **HTML5 & CSS3:** Modern styling, flexbox layouts, and responsive design structures.
* **JavaScript (ES6+):** Core application logic and array manipulation methods.
* **Git & GitHub:** Version control and repository hosting.
